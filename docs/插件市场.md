# 插件市场安装与收录

工作流画布（Workflow Canvas）是 DeepSeek Harness 的可视化 AI 项目工作台，提供资料到文章、自定义文件任务，以及配置后的程序动画视频流程。

## 当前状态

- RC1 已在 [GitHub Releases](https://github.com/zzz123123lll/workflow-canvas-sidebar/releases/tag/v0.17.0-rc.1) 公开，完整 ZIP 可手动安装。
- RC2（`0.17.0-rc.2`）正在准备完整 npm 市场包，包名为 `dsh-workflow-canvas-sidebar`。
- 本文写入时尚未确认 npm 发布或市场收录；以下市场安装步骤在该版本发布后适用。包准备、发布和审核是各自独立的状态。

## 从市场安装

Windows x64，宿主基线 DeepSeek Harness `0.2.1-rc.5`。在 Harness「插件 → 添加插件」输入：

```text
dsh-workflow-canvas-sidebar@0.17.0-rc.2
```

也可以运行：

```powershell
dsh plugin --profile desktop add dsh-workflow-canvas-sidebar@0.17.0-rc.2
```

重启 Harness，打开左侧“画布”，从“资料到文章”开始第一次任务。完整 npm 包自带 Python 和锁定依赖；无需另跑 `install.cmd`，不通过 `install` / `postinstall` 脚本下载运行时。模型任务仍使用用户自己的 Harness 账号和所配置的模型。视频需另配 Node、Chrome、FFmpeg 和 Remotion，见 [视频配置](视频配置.md)。

RC2 计划使用 npm 的 `next` 候选标签，请固定版本安装。待市场收录后，用户添加 [开放市场索引](https://dshopen.org/zh/) 才能在对应索引中找到插件；提交申请不等于审核通过。

### 已有 ZIP 用户

默认数据目录仍是 `%USERPROFILE%\.dsh-workflow-canvas`，不会随包更新替换。若之前的 `canvas-home.json` 指向自定义数据目录，切换前记录该目录和所需工具配置，让市场包继续使用相同配置；不要同时启用旧 ZIP 与市场包的两个画布实例。先解除旧插件登记时保留数据，具体操作见 [升级与恢复](升级与恢复.md)。

任务资料会按你的操作交给 Harness 配置的模型或工具；分享项目默认排除账号、会话和机器配置，资料由用户选择是否附带。诊断报告只在本地生成，不会自动上传。

## 构建与发布材料

```powershell
python scripts/build.py --output dist
python scripts/npm_package.py --release-dir dist
```

主要产物：

- `workflow-canvas-sidebar-v0.17.0-rc.2-windows-x64.zip`
- `dsh-workflow-canvas-sidebar-0.17.0-rc.2.tgz`
- `release-manifest.json`、`npm-manifest.json` 和校验值

npm 包从完整 ZIP 构建，保留同一批运行代码、入口、原创模板和运行时。发布者应核对包内 `package.json` 的 `dsh.bundle.patch`，以及补丁、前端入口、自带 Python、依赖和许可文件都已包含，然后验证新数据目录下的安装与启动。实际测试、构建提交与哈希应附在申请中。
