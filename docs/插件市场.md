# 插件市场安装与收录

工作流画布（Workflow Canvas）是 DeepSeek Harness 的可视化 AI 项目工作台，提供资料到文章、自定义文件任务，以及配置后的程序动画视频流程。

## 当前状态

- RC2 已发布，但市场维护者确认其解压体积为 313,220,673 字节，超过 256 MiB，因此未收录，也尚未完成运行代码复核；见[审核反馈](https://github.com/polang233/dsh-plugin-index/issues/201#issuecomment-6579081928)。
- RC3（`0.17.0-rc.3`）精简为内置 CPython + pypdf，AI 通过现有 Harness 宿主子会话执行。不再分发独立 SDK/第二份 Harness 运行时，也不在首次启动时下载或展开它。
- [收录申请 #201](https://github.com/polang233/dsh-plugin-index/issues/201)仍待新版复核；npm 发布不等于市场审核通过。

## 从市场安装

Windows x64，宿主基线 DeepSeek Harness `0.2.1-rc.5`。在 Harness「插件 → 添加插件」输入：

```text
dsh-workflow-canvas-sidebar@0.17.0-rc.3
```

也可以运行：

```powershell
dsh plugin --profile desktop add dsh-workflow-canvas-sidebar@0.17.0-rc.3
```

重启 Harness，打开左侧“画布”，从“资料到文章”开始第一次任务。完整 npm 包自带 Python 和锁定依赖；无需另跑 `install.cmd`，不通过 `install` / `postinstall` 脚本下载运行时。模型任务仍使用用户自己的 Harness 账号和所配置的模型。视频需另配 Node、Chrome、FFmpeg 和 Remotion，见 [视频配置](视频配置.md)。

RC3 使用 npm 的 `next` 候选标签，请固定版本安装。待市场收录后，用户添加 [开放市场索引](https://dshopen.org/zh/) 才能在对应索引中找到插件；提交申请不等于审核通过。

### 已有 ZIP 用户

默认数据目录仍是 `%USERPROFILE%\.dsh-workflow-canvas`，不会随包更新替换。若之前的 `canvas-home.json` 指向自定义数据目录，切换前记录该目录和所需工具配置，让市场包继续使用相同配置；不要同时启用旧 ZIP 与市场包的两个画布实例。先解除旧插件登记时保留数据，具体操作见 [升级与恢复](升级与恢复.md)。

任务资料会按你的操作交给 Harness 配置的模型或工具；分享项目默认排除账号、会话和机器配置，资料由用户选择是否附带。诊断报告只在本地生成，不会自动上传。

## 构建与发布材料

```powershell
python scripts/build.py --output dist
python scripts/npm_package.py --release-dir dist
```

主要产物：

- `workflow-canvas-sidebar-v0.17.0-rc.3-windows-x64.zip`
- `dsh-workflow-canvas-sidebar-0.17.0-rc.3.tgz`
- `release-manifest.json`、`npm-manifest.json` 和校验值

npm 包从完整 ZIP 构建，保留同一批运行代码、入口、原创模板和运行时。发布者应核对包内 `package.json` 的 `dsh.bundle.patch`，以及补丁、前端入口、自带 Python、依赖和许可文件都已包含，然后验证新数据目录下的安装与启动。实际测试、构建提交与哈希应附在申请中。

## 开放插件市场收录申请

沿用[原申请 #201](https://github.com/polang233/dsh-plugin-index/issues/201)，新版固定为 `dsh-workflow-canvas-sidebar@0.17.0-rc.3`。
构建时 `npm-manifest.json` 记录实际 `unpacked_bytes`，超过 268,435,456 字节会直接拒绝打包。ZIP 与 npm TGZ 保持相同文件，使用无安装钩子的离线安装验证。

入口仍为 `package.json` → `dsh.bundle.patch` → `cordis.patch.yml` → `index.js`。内置 Python 启动本地 API 和 PDF 解析；AI 通过 Harness 的现有公开子会话服务运行。宿主断开时保留会话和文件，提示恢复 Harness，不转而索要独立 API key。

许可与组件清单见 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)。视频依赖仍由使用者按需配置。新版实际构建、完整性、安装证据和公开发布状态见对应 [GitHub Release](https://github.com/zzz123123lll/workflow-canvas-sidebar/releases/tag/v0.17.0-rc.3)；代码复核与是否收录由维护者决定。
