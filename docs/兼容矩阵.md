# 兼容、能力与已知限制

|内容|范围|
|---|---|
|发行平台|Windows x64；本机Windows11实测，独立标准用户/其他机器覆盖按验收表记录|
|宿主基线|DeepSeek Harness0.2.1-rc.5；创建/继续/公开事件/取消/原生打开/重开均需对应实测|
|其他系统/宿主版本|未声明正式支持；欢迎兼容报告，不把未测试版本写成已通过|
|资料任务|完整包自带本地依赖，模型使用自己的Harness账号并需联网|
|资料解析|文本、含文字PDF、可用Windows OCR图片；扫描PDF需补充OCR文本|
|视频|配置后的Remotion程序动画、字幕和合成提示音；外部真人配音/图生视频未默认接通|
|并发|独立分支可保留；AI节点串行、渲染串行，不为速度制造重叠执行|
|实例|每个数据目录一个活动宿主/profile；不同数据目录通过独立端口和令牌隔离|
|公开试用|用户选择免费开源后收集反馈，未实施三人真人验收，不伪造参与者|

早期宿主发生过Undici断言退出，插件采用NodeHTTP流式回环代理并验证恢复，不声称修复宿主本体。路径权限与受限工具不是未经证明的完整OS隔离。长文有上下文预算，采用记录保留片段与遗漏情况；OCR内容需对图核对。

原生媒体地址1小时到期后刷新成果页即可重新取得。AI流程建议仍需审阅，采用不会自动执行。内容审阅仅对指定代次/hash生效；AI或维护者验收不是用户对外发布批准。项目分享当前限AI模块；自定义程序执行器与本机校验需要按扩展文档单独配置。

当前候选的逐项验证、真实点击范围及未覆盖环境见发行acceptance，不用本页的能力描述代替证据。
