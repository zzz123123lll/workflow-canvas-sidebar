# 免费开源试用与推广材料

## 一句话介绍

工作流画布是DeepSeek Harness里的可视化AI项目工作台：给一个目标，让多个AI步骤协作，持续讨论、局部改稿，拿到有来源和版本的成果。

## 发布文案

我把自己使用的AI工作流画布开源了。它把项目目标、资料、流程、模块对话和成果放在同一处，支持文章研究、结构化文件任务，以及配置后的30秒程序动画视频。改稿保留旧版本，只更新受影响步骤；遇到失败可以保留有效工作再继续。

目前提供Windows候选安装包、中文/英文快速开始、源码、构建脚本和验收记录。插件免费，模型账号与可选工具按各自条件使用。欢迎试用后反馈安装、第一次任务和导出过程中最卡的一步。

## 无需付费的反馈方式

直接开放候选包，让愿意使用的人按README尝试，不购买测试者或承诺奖励。反馈模板：系统/宿主、版本build、选择的模板、做到哪一步、预期/实际、能否继续及可选脱敏诊断。不要索取账号、令牌或完整私人对话。

不设人数作为候选发布前置，也不声称已通过三位陌生用户验收。先跟踪会影响安装、任务完成和成果取得的阻塞，再处理排版和新增模板需求。

## 建议演示顺序

项目总览选择“资料到文章”→替换资料与目标→真实运行→回答待办→阅读和审阅→局部改稿→查看历史/下载；第二段展示新制作视频的片尾改稿、实际播放和交付ZIP。演示只使用原创合成项目，不露出个人会话或账号侧栏。
