# 配置短视频制作

首发模板制作30秒、640×360、15fps的原创程序动画，带字幕与轻柔合成提示音，无旁白。它使用真实AI分镜、工程制作和Remotion渲染，不调用付费生图/视频服务。

安装可用的Node、Chrome和FFmpeg。Remotion依赖独立装在你选择的目录，例如：

```powershell
mkdir C:\Tools\CanvasVideo
cd C:\Tools\CanvasVideo
npm init -y
npm install --save-exact remotion@4.0.539 @remotion/bundler@4.0.539 @remotion/renderer@4.0.539 react@18.3.1 react-dom@18.3.1
```

把该目录的package-lock.json保留在本机以固定传递依赖。视频工具不在核心完整包内；此命令需要联网下载，但不会自动购买服务。Remotion的使用许可与插件MIT不同，请按[官方条款](https://www.remotion.dev/docs/license)核对用途。

打开项目总览→环境与视频工具，填写node.exe、chrome.exe、ffmpeg.exe、ffprobe.exe的真实绝对路径，以及上述node_modules目录。保存并检测。缺少任一必要项会明确显示，保留已完成步骤；配置后在对应待办回复并继续，当前尝试会记录工具配置摘要。

先运行“简短动态图形视频”。需要调整时在分镜或工程节点提出可观察要求，例如“把片尾改成指定句子”；创建修订后仅更新受影响下游，旧成片保留。成果页实际播放、拖动、调音量并切换代次，读完制作说明后审阅，再下载含字幕/工程/说明的交付包。

渲染代理固定当前工作区，停止后回收进程树；它不是完整OS沙箱。不要通过更改系统安全设置来解决缺工具问题。当前证据只覆盖程序动画，不等于所有真人配音、图生视频和外部生成服务均可用。
