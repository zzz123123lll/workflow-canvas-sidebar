# 开发、测试和构建

源码根仅包含插件、原创seed、测试、文档和构建脚本。runtime、机器配置、.runs、用户数据、缓存和旧本机证据均不进Git。

受测开发工具：Python3.12、Node24、PowerShell7。Windows是本次发行目标。新checkout执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install --require-hashes -r requirements-dev.lock.txt
.\.venv\Scripts\python -m pip install --require-hashes -r requirements.lock.txt
.\.venv\Scripts\python scripts/verify.py
.\.venv\Scripts\python scripts/build.py --output dist
```

verify会打印实际解释器和server路径，并为全部测试创建临时CANVAS_HOME，不接触正式项目。CI执行同一入口；真实账号、原生会话和视频操作另外验收，不能由无账号CI替代。

构建从dependencies.lock.json的官方Python ZIP/PyPI wheel获取依赖，验证SHA后解压组装，不解析浮动版本，不复制正式数据或维护者venv。需要预热/离线构建可传`--cache <目录>`和`--offline`；缺缓存会准确失败。输出完整ZIP、SHA256SUMS、manifest、依赖清单、notices和说明。ZIP条目时间、路径与权限规范化，内容一致时归档字节一致。

开发连接宿主时复制发行包到单独固定路径，设置独立CanvasHome后登记到测试profile；使用自己的账号，不提交登录资料。调试构建显示version+build_id+schema。正式更新前对当前安装做备份和状态核对。

新增AI模块可从wc17-file-transform复制，修改id/name/agent_prompt、requires、artifacts、checklist及deliveries。输入绑定映射声明路径到生产节点ID；目录工程也需要声明。请给出最小有价值的回归：缺输入、版本来源、必要附件或取消边界，不写复制实现的断言。参考tests/test_project_overview.py与tests/test_project_sharing.py。
