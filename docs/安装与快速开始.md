# 安装与第一个成果

1. 安装受测的Harness桌面版并启动一次，登录自己的账号。受测基线0.2.1-rc.5；未知版本会做能力探测，未测试不等于已保证兼容。
2. 安装免费的PowerShell 7。Windows内置5.1不是7；缺少时install.cmd会给出官方安装地址，或执行 `winget install --id Microsoft.PowerShell --source winget`。无需全局关闭执行策略。
3. 解压完整Windows x64发行包到固定目录。下载文件若被Windows标记为来自网络，只解除本次包内脚本的文件阻止；不要降低系统全局策略。
4. 双击install.cmd，或在PowerShell 7执行 `./install.ps1 -RegisterProfile`。默认数据目录为 `%USERPROFILE%\.dsh-workflow-canvas`，可用 `-CanvasHome 'C:\My Projects\画布资料'` 自定义。
5. 重启Harness，打开画布。核对标题版本；环境检测中的源路径、build和数据目录可帮助确认加载身份。

完整包带 Python 与 PDF 解析依赖。AI 步骤直接使用 Harness 宿主账号和子会话，不再捆绑另一份独立 SDK 运行时。普通文档任务无需全局 Python/Node；安装时本地依赖齐全就不调用 pip。宿主连接中断时恢复 Harness 即可，无需另配 API key。

## 第一个真实AI项目

项目总览→资料到文章→填写目标/受众/交付要求→保存项目。可以直接体验原创共享示例，也可在“资料”中上传项目文件，给节点声明必读资料。共享示例不是已批准的真实活动。

先看流程中的职责和交付要求，再点击运行。AI提出问题时从待办打开工作区，填写答案并继续。解释或普通追问用“讨论”；需要改变成果用“修订”，先查看影响范围。完成后阅读正文与来源，在要求内容审阅的节点确认本代内容，再到成果页下载。

## 继续与修改

当前工作运行是你正在推进的执行；当前交付版是已选择保留给下载的成果。两者可以不同。历史失败仍可查，但不会混在当前待办里；只有你点击“由当前工作运行替代”，才登记旧运行的替代关系。

暂停在当前步骤结束后生效；停止会取消活动模型和工具。重开先核对状态；结果不确定时显示需对账，不盲目重跑。原生聊天改文件后先同步、登记新版本，再审阅，不沿用旧审核。

## 分享与反馈

交付ZIP保存成果及清单；模板导出保存定义；项目包保存定义和可选项目资料。默认不含账号、会话、历史成果、共享资料和机器配置，导入后不会自动运行。导入的本机程序校验/工具和明确项目路径需要重新配置。

遇到问题使用仓库Issue模板。诊断包默认只有版本/build、系统与状态计数，可先查看包含项，不含私有对话。安装、模型或视频缺依赖的错误应保留原文，按定位修复后继续。
